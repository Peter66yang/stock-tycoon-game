# ✈️ 機場管制遊戲 — 設計筆記

> 設計師：我（國小五年級）
> 這份筆記記錄了我對這個遊戲的所有決定，做遊戲的時候要照著做！

## 遊戲是什麼？

玩家是機場塔台的**航空管制員**，要指揮飛機降落、開到停機坪、再起飛，不要讓飛機撞在一起。

- 這是一個**輕鬆的機場模擬遊戲**
- **永遠不會輸**，可以一直玩下去
- **沒有分數**，享受當管制員的感覺

## 飛機的路線

```
🛬 降落（跑道）→ 滑行道 → 🅿️ 停機坪 → 🦀 螃蟹車推出 → 滑行道 → 🛫 起飛（跑道）
```

- 遊戲一開始，機場是**空的**，沒有飛機
- 飛機先降落、停好，之後才會被推出去起飛

## 機場

| 東西 | 數量 / 樣子 |
|---|---|
| 跑道 | 2 條，**交叉**成 X 形 |
| 停機坪 | 10 個 |
| 滑行道 | 把跑道和停機坪連起來 |

## 航班表

| 航班代碼 | 時間 | 跑道 | 停機坪 |
|---|---|---|---|
| KX582 🛬 | 10:30 | 玩家填 | 玩家填 |
| TM7031 🛫 | 10:45 | 玩家填 | ❌ 起飛不用填 |

- **航班代碼**：2 個英文字母 + 3 個或 4 個數字，電腦隨機產生（兩種長度混在一起出現）
- **時間**：幾點幾分起飛或降落，由**電腦決定**
- **跑道、停機坪**：由**玩家自己填**
- 每 **30 秒**出現一架新的航班

## 怎麼操作？

- **點一下格子** → 跳出選項 → 選一個
- 例如點「跑道」格子 → 跳出「1 號跑道 / 2 號跑道」→ 選一個

## 規則

| 狀況 | 會發生什麼 |
|---|---|
| 停機坪已經有飛機 | 🚫 不能選這個停機坪（變灰色） |
| 停機坪全滿，又有飛機要降落 | 飛機可以先降落，**停在跑道上等**停機坪空出來 |
| 跑道也都有飛機在等 | 🔄 要降落的飛機在**天上繞圈圈**等 |
| 起飛時間到了 | 🦀 螃蟹車**自動**把飛機從停機坪推出來 |
| 被推出來了，可是玩家還沒填跑道 | 飛機**停在滑行道上等**玩家填 |
| 兩架飛機快要同時經過跑道交叉點 | ⚠️ 遊戲提醒，**兩架都停下來等**，玩家**點一架**先走 |

## 💡 我發現的好玩地方

玩家要像下棋一樣**想好順序**。例如停機坪和跑道都塞滿的時候：

1. **先**讓螃蟹車把要起飛的飛機推出來 → 停機坪空出一個
2. **再**讓跑道上等待的飛機開進那個空停機坪 → 跑道空了
3. **最後**要起飛的飛機去空出來的跑道起飛

順序弄錯，機場就會塞住！
